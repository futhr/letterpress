# Agent instructions

Read and follow `CLAUDE.md` first. It is the canonical repository contract for
architecture, public behavior, documentation, quality gates, and the referenced
`.claude/` standards and skills.

Do not duplicate or reinterpret those rules here. This file exists so agents
outside Claude Code can discover the same project instructions quickly.

Canonical skills live under `.claude/skills/` and are selected from their
descriptions. Clients without native skill discovery should read the matching
`SKILL.md` and run `mix check` before handing off completed work.
