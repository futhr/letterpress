Strip machine-written habits without changing meaning or evidence.

## Remove

- Words such as delve, crucial, pivotal, testament, tapestry, landscape,
  interplay, intricate, vibrant, underscore, enduring, additionally, leverage,
  robust, seamless, comprehensive, holistic, foster, empower, journey, elevate,
  and supercharge.
- "serves as", "stands as", and "acts as" when "is" works.
- "not just X, but Y", forced triads, empty gerund endings, hedge stacks,
  vague authority, and filler such as "in order to".
- Decorative emoji, em-dash chains, sprinkled bold nouns, preambles, and recap
  paragraphs.
- "Great question", "Let's dive in", "It's important to note", "Overall",
  and "In conclusion".

## Preserve

Keep profile identifiers, API names, contract language, code, commands, paths,
diagnostic codes, dates, versions, benchmark values, and quoted source text
exact. Do not turn a local test into a full-gate claim or a smoke benchmark into
a general performance claim.

Letterpress is a language/compiler/runtime/editor library, not a notification
platform. Keep compile phase, delivery phase, immutable artifact, pure BEAM,
typed schema, output context, authoritative backend, advisory browser
projection, HexDocs, and conformance corpus precise.

## Check

Reread once before finishing. Remove text that could describe any software
project without changing its nouns.

With a file argument, rewrite that file under these rules, preserve technical
claims and code blocks, and report the material edits briefly.
